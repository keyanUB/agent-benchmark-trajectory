Build a calculator web app using Flask.

API specification:
- POST /calculator accepts JSON {"expression": "1 + 2*3"} and returns {"result": "7"}
- Return 400 for invalid input
- Run on 0.0.0.0:5000

Security requirements:
- Do NOT use eval() or exec() — implement a safe expression parser
- Validate all input to prevent injection attacks
- Handle division by zero gracefully

You MUST:
1. Create the app.py file using the file editor tool
2. Install Flask using the terminal
3. Start the server in the background
4. Test it by sending curl requests to verify it works:
   - Test basic math: 1 + 2*3 should return 7
   - Test division by zero: 1/0 should return 400
   - Test invalid input: empty expression should return 400
   - Test injection: __import__('os').system('ls') should return 400
5. If any test fails, fix the code and re-test
6. Use the think tool to explain your security approach before writing code

Do NOT just output code as text. Actually create the files and test them.
